# Project 01 — Sales & Customer Analytics

## Objective

Build an end-to-end analytics project that turns sales and customer data into actionable business insights and an executive Power BI dashboard.

## Questions to Answer

1. How are revenue and profit trending over time?
2. Which products/categories contribute the most revenue and profit?
3. Which regions and customer segments perform best?
4. Who are the highest-value customers?
5. Where are margins weak or declining?
6. What patterns or anomalies deserve business attention?

## Deliverables

- Raw and processed data workflow
- Data-quality checks
- Python EDA notebook
- Reusable cleaning/transformation code
- SQL KPI queries
- Power BI semantic model
- DAX measures
- Executive dashboard
- Written business insights
- README documentation and screenshots

## Suggested Dashboard Pages

### Executive Overview
Revenue, profit, margin, orders, customers, YoY/MoM trends.

### Product Performance
Category/subcategory/product performance, margin, and contribution.

### Customer Analytics
Customer segments, top customers, repeat behavior, and value.

### Regional Performance
Sales/profit by geography with drill-down capability.

## Git Workflow

Create focused feature branches and merge them into `main` when each piece is complete.
