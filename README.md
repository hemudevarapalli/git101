# Data Science & Power BI Portfolio

A hands-on portfolio for end-to-end data analytics projects using Python, SQL, data science, and Power BI.

## Goals

- Clean and transform real-world datasets
- Perform exploratory data analysis (EDA)
- Build reusable Python data pipelines
- Practice SQL analysis
- Create business-focused Power BI dashboards
- Document insights and decisions clearly
- Use Git and GitHub for version control

## Project Structure

```text
data/
  raw/          # Original source data (usually not committed)
  processed/    # Cleaned/transformed outputs
notebooks/      # Jupyter notebooks for exploration and analysis
src/            # Reusable Python code
sql/            # SQL queries and scripts
powerbi/        # Power BI project/report assets
reports/        # Exported reports, figures, and summaries
docs/           # Project documentation
```

## First Portfolio Project

**Sales & Customer Analytics Dashboard**

Planned workflow:
1. Ingest a sales/customer dataset.
2. Clean and validate data with Python.
3. Explore revenue, profit, products, customers, regions, and trends.
4. Build SQL queries for core business KPIs.
5. Create a Power BI data model and DAX measures.
6. Build an executive dashboard.
7. Document findings and publish the project through GitHub.

## Tech Stack

- Python
- pandas / NumPy
- Jupyter
- SQL
- Power BI
- Git & GitHub

## Git Workflow

Use `main` for stable work. Create feature branches for meaningful changes, for example:

- `feature/data-cleaning`
- `feature/eda`
- `feature/sql-analysis`
- `feature/powerbi-dashboard`

Commit small, understandable changes and use pull requests when merging completed features.
